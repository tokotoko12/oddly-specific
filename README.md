# 妙に具体的な今日の指令

押すたびに、どうでもいいのに妙に具体的な「今日の指令」が出る1ページ完結のミニサイトです。

## Features

- 奇妙さを1〜5段階で選択
- ランダムな指令を生成
- 押した回数、人生の余白、現在の状態をブラウザ内に保存
- 最近の指令を5件まで表示
- スペースキーで再抽選
- スマートフォン対応
- 外部API、ログイン、個人情報入力なし

## GitHub Pages

GitHubの `Settings` → `Pages` を開き、`Build and deployment` の `Source` を `Deploy from a branch` に設定します。

Branch は `main`、folder は `/(root)` を選択して保存してください。

公開URLは通常、次の形式になります。

`https://tokotoko12.github.io/oddly-specific/`

## Files

- `index.html` : HTML、CSS、JavaScriptを含むサイト本体

## Notes

指令は娯楽目的です。危険、迷惑、違法になり得る行動は意図的に含めていません。
